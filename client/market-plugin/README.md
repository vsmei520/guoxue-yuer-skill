# 曾美团队·育儿国风穿越

古今对话短剧 AI 视频生产系统。

## 功能特点

- **远程授权模式**：核心规则存储在远程服务器，本地插件只负责授权和调用
- **一机一码绑定**：使用手机号和授权码激活，授权信息加密保存在本机
- **分阶段创作**：从钩子分析到发布标题，8 个阶段完整输出视频生产物
- **服务端 AI**：AI 模型由服务器统一配置，用户无需自备 API 密钥

## 使用流程

### 1. 首次激活

在 Claude 中输入：

```
启动曾美团队·育儿国风穿越
```

插件会提示你调用 `activate_license` 工具，打开本地激活页面。填写：

- **手机号**：用于绑定授权
- **授权码**：由管理员提供

激活成功后，授权信息会加密保存在你的电脑上。

### 2. 检查状态

随时可以调用 `auth_status` 工具查看当前授权状态。

### 3. 开始创作

激活后，在 Claude 中输入选题和构思，例如：

```
帮我生成一个育儿国风短视频

选题：孩子不爱吃饭怎么办

初步构思：通过苏轼的故事，讲述"食不厌精"的智慧
```

插件会自动执行 8 个阶段的创作流程。

## 授权说明

- **一机一码**：每个授权码只能绑定一台电脑
- **本地存储**：授权信息使用系统加密保存在本机，不会上传
- **更换设备**：需要联系管理员解绑后重新激活

## 系统要求

- Node.js 18 或更高版本
- Windows、macOS 或 Linux
